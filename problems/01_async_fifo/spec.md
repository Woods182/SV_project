# 异步 FIFO：规格澄清清单

状态：DRAFT；以下均为待确认项，不是冻结规格。

## 1. 功能与参数

- [ ] `DATA_WIDTH` 默认值与合法范围是什么？建议首练 8 或 32 bit。
- [ ] 深度是否限定为 `2**ADDR_WIDTH`？经典 Gray 指针方案建议首练限定 2 的幂。
- [ ] 选择 `ADDR_WIDTH` 参数，还是直接暴露 `DEPTH` 并在 elaboration 检查合法性？
- [ ] 是否只要求 `full/empty`，还是加入 `almost_full/almost_empty`、计数或错误标志？首练建议只做空满。
- [ ] 存储体目标是通用寄存器数组、FPGA BRAM，还是 ASIC 双口 SRAM 宏的可替换接口？

## 2. 接口语义

- [ ] 写侧是否采用 `wr_en && !full` 才接受数据？满时写请求是静默丢弃、保持还是报错？
- [ ] 读侧是否采用 `rd_en && !empty` 才弹出数据？空读如何处理？
- [ ] 读数据模式：标准读（接受读请求后若干拍有效）还是 FWFT/show-ahead？
- [ ] 是否提供显式 `wr_accept` / `rd_valid`，避免只靠请求和空满推断事务？
- [ ] 同一地址附近跨域读写时，底层 RAM 的 read-during-write 行为由谁保证？

## 3. 时钟与复位

- [ ] `wr_clk` 与 `rd_clk` 是否完全异步，允许任意频率比、抖动和相位漂移？建议是。
- [ ] 每个域是否有独立低有效异步复位 `wr_rst_n` / `rd_rst_n`，并在域内同步释放？
- [ ] 两个复位是否保证同时拉低/按顺序释放？如果某一域单独复位，FIFO 中在途数据如何定义？
- [ ] 复位后允许多久才对空满、读写请求作出有效响应？同步器和指针初始化需要明确周期数。
- [ ] 是否要求 CDC/综合属性（如 `ASYNC_REG`）以及约束脚本接口？属性语法与目标工具相关，不能先猜。

## 4. 吞吐、延迟与状态保守性

- [ ] 非满时写侧是否必须每个 `wr_clk` 接受 1 word？
- [ ] 非空时读侧是否必须每个 `rd_clk` 交付 1 word？
- [ ] 从首次写入到读侧看到 `empty=0` 允许多少个 `rd_clk` 周期？
- [ ] 从读出腾出空间到写侧看到 `full=0` 允许多少个 `wr_clk` 周期？
- [ ] 是否接受经典双触发同步导致的保守去空/去满延迟？安全优先，不能提前宣称空或满已解除。

## 5. 指针与边界

- [ ] 二进制指针和 Gray 指针是否都使用 `ADDR_WIDTH+1` 位以区分环绕？
- [ ] 满判断采用哪一代 Gray 指针公式，如何参数化到最小合法深度？必须专门测试位切片边界。
- [ ] 同步器级数固定为 2，还是参数化？首练建议固定 2，避免把 MTBF 设计伪装成普通功能参数。
- [ ] 是否允许深度 2？深度 1 是否明确禁止？
- [ ] 指针跨域只传 Gray 码；本地二进制地址不逐 bit 同步，此项是否作为硬性约束？

## 6. 验收标准

- [ ] self-checking scoreboard 以接受的写事务为入队、接受的读事务为出队，逐 word 比较且保持顺序。
- [ ] 测试频率比至少包含写快/读慢、写慢/读快、近频异相和运行中随机空闲。
- [ ] 覆盖 wrap-around、多次满/空切换、满写/空读抑制、复位启动；独立域复位只在语义冻结后测试。
- [ ] 加入基本断言：不接受满写、不接受空读、Gray 指针每次有效推进最多 1 bit 变化（工具支持时）。
- [ ] lint、仿真、SVA、波形、综合/CDC/STA 分开记证据；其中任一通过不能替代其余项目。

## 建议的首练默认值（需用户确认）

`DATA_WIDTH=8`、`ADDR_WIDTH=4`（深度 16）、完全异步双时钟、两个低有效异步复位且各自在本域同步释放、标准读接口、只输出 `full/empty`、满写和空读不接受、每域峰值 1 word/clock、经典双触发 Gray 指针同步。
