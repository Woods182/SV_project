# 异步 FIFO：冻结规格

状态：VERIFIED（冻结日期：2026-09-02）

## 功能与参数

- 模块名：`FIFO`。
- `DATA_WIDTH >= 1`，默认值为 8。
- `ADDR_WIDTH >= 2`，默认值为 4。
- 深度固定为 `DEPTH = 2**ADDR_WIDTH`。
- 第一版只提供 `wfull` 和 `rempty`，不提供 almost-full/empty、计数或错误标志。
- 存储体使用通用 SystemVerilog 数组，不绑定特定 FPGA BRAM 或 ASIC SRAM 宏。

## 接口语义

- 写事务仅在 `winc && !wfull` 时接受；满时写请求被阻止。
- 读事务仅在 `rinc && !rempty` 时接受；空时读请求被阻止。
- 采用标准寄存读接口：成功读出后 `rdata` 更新，其他时间保持。
- 不额外提供 `wr_accept` 或 `rd_valid`，事务接受状态由请求和空满标志共同判断。
- 非满/非空时，每个本地时钟周期最多接受一个 word。

## 时钟与复位

- `wclk` 与 `rclk` 完全异步，允许任意频率比和相位关系。
- 写域使用低有效异步复位 `wrst_n`，读域使用低有效异步复位 `rrst_n`。
- 两个复位必须共同异步拉低，并在各自时钟域同步释放。
- 不支持运行期间只复位单个时钟域；需要 flush 时应同时复位两个域。
- 复位后写侧为非满，读侧为空，指针及同步器清零。

## 指针、CDC 与空满判断

- 二进制读写指针和 Gray 指针均为 `ADDR_WIDTH+1` 位，用额外最高位区分地址回绕。
- 本地二进制指针仅用于地址和递增，不跨时钟域。
- 跨域只传输 Gray 指针，每个方向使用两级同步寄存器。
- 读域以“下一读 Gray 指针等于已同步写 Gray 指针”判断 empty。
- 写域以“下一写 Gray 指针等于已同步读 Gray 指针最高两位取反后的值”判断 full。
- 空满解除允许包含两级同步器带来的保守延迟。

## 验收标准

- self-checking scoreboard 只记录已接受的写事务，并对每个已接受的读事务逐 word、按顺序比较。
- 覆盖复位启动、空读、满写、完整填满/排空、多次 wrap-around 和随机空闲。
- 覆盖写快读慢、写慢读快以及近频异相三类时钟关系。
- 检查被阻止的请求不会推进指针，以及本地 Gray 指针单次有效推进最多改变 1 bit。
- Verible lint、VCS 功能仿真和 Yosys 结构检查均须通过。

## 验证边界

当前完成状态只覆盖冻结规格及 RTL 级工具验证，不代表目标工艺下的 CDC 静态检查、STA、RAM 映射、门级仿真或形式验证已经完成。
