# 异步 FIFO：架构讲解

状态：VERIFIED

## 主体架构

FIFO 由双口存储数组、写域指针逻辑、读域指针逻辑和两组 Gray 指针同步器组成。写数据只受 `wclk` 控制，读数据只受 `rclk` 控制；两个时钟域不直接使用对方的二进制指针。

每个域都维护一份本地二进制指针和对应 Gray 指针。二进制指针便于地址索引和加一，Gray 指针用于跨域，因为合法递增时相邻编码最多变化一个 bit，可降低多 bit 指针跨域采样不一致的风险。

## 数据通路

- 写侧在 `winc && !wfull` 时，把 `wdata` 写入 `mem[wbin[ADDR_WIDTH-1:0]]`。
- 读侧在 `rinc && !rempty` 时，从 `mem[rbin[ADDR_WIDTH-1:0]]` 更新寄存输出 `rdata`。
- 地址只取二进制指针低 `ADDR_WIDTH` 位；额外最高位只用于区分环绕。

## 控制与指针通路

- `wpush = winc && !wfull`，仅在写请求被接受时推进写指针。
- `rpop = rinc && !rempty`，仅在读请求被接受时推进读指针。
- 下一二进制指针经 `gray = bin ^ (bin >> 1)` 转换为下一 Gray 指针。
- `rempty` 使用下一读 Gray 指针与读域同步后的写 Gray 指针比较。
- `wfull` 使用下一写 Gray 指针与写域同步后的读 Gray 指针比较；最高两位取反表示地址相同但相差一整圈。

空满标志在各自本地时钟域寄存。远端指针同步存在延迟，因此 empty/full 的解除是保守的：可能晚几个本地周期，但不会因直接使用异步指针而提前解除。

## CDC、STA 与综合注意点

- 只允许 Gray 指针跨域，禁止逐 bit 同步二进制指针后重新拼接。
- 两级同步寄存器应在实现工具中标记为异步同步链，并为 Gray 总线设置合理的最大延迟/偏斜约束。
- `ASYNC_REG` 属性不能替代 CDC 报告和 STA 约束。
- 两个复位需共同异步拉低、分别同步释放；单域复位会破坏两域对 FIFO 内容的一致认知。
- 通用双时钟数组的 BRAM/SRAM 推断和 read-during-write 行为依赖目标工艺，流片或 FPGA 实现前需单独确认。
- 当前 RTL 仿真无法模拟真实亚稳态，只能验证同步结构和功能协议。

## 常见面试追问

1. 为什么跨域传 Gray 指针而不是二进制指针？因为二进制加一可能同时翻转多位，异步采样可能得到不存在的组合；Gray 相邻值最多变化一位。
2. 为什么指针需要多一位？低位给出 RAM 地址，额外位区分同地址下的“空”和“已绕回一圈而满”。
3. 为什么 full 要反转同步读指针的最高两位？经典反射 Gray 编码中，相差一圈且地址相同的指针表现为最高两位相反、其余位相同。
4. 两级同步会带来什么影响？降低亚稳态传播概率，同时使去空、去满出现安全的保守延迟。
5. 仿真 PASS 是否证明 CDC 安全？不能；还需要 CDC 静态检查、约束审阅和目标工艺下的时序分析。
